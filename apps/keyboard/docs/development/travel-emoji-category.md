# Travel Emoji Category — Development

GoreeCloud Keyboard now includes a sixth fully local emoji category for travel, transport, and destinations.

## Behavior

- Travel is exposed through the existing compact enum-driven emoji category strip.
- The category contains three bounded rows of eight emoji each.
- It participates in the existing remembered local category preference automatically.
- Emoji insertion and sequence-aware backspace behavior are unchanged.
- No network request, remote catalog, telemetry, account state, permission, or synchronization is introduced.

## Boundary

Development only. No online emoji search, cloud personalization, remote authority, or Stable qualification is added.
