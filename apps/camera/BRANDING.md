# GoreeCloud Camera — Branding

> Repository document version: **0.1.0**  
> Product internal version: **0.1.0**  
> Release lifecycle: **Concept**

## Canonical product name

**GoreeCloud Camera**

## Product identity

GoreeCloud Camera should communicate trustworthy capture, privacy and user ownership, professional capability, creative expression, local-first operation, and calm/understandable state.

## Interface system

The application must use the current accepted **Glaze UI** consumer contract. The current portfolio target is **1.4.1**.

Glaze UI conformance is not currently implemented or accepted. The repository must not display compliance claims until application-specific evidence exists.

## Viewfinder principle

The live image is the visual focus. Glass, translucency, blur, adaptive contrast, motion, haptics, and status color should clarify controls/state without obscuring the scene.

## Status communication

Recording, Private Capture, microphone use, location, Lens processing, remote control, thermal pressure, storage risk, and other critical states must remain understandable and must not rely on color alone.

## Assets

No Camera-specific icon, logo asset package, splash artwork, or store artwork is verified in this repository at the Concept baseline. Future assets must come from approved GoreeCloud branding sources and follow applicable accessibility and platform requirements.
